The first release of PicoBoot-WiFi: PicoBoot-DX for the Raspberry Pi Pico 2 W, with updates over Wi-Fi.

**What it does:** it boots a payload at every power-on (Swiss, gekkoboot, any PicoBoot payload), then runs a Wi-Fi access point, `PicoBoot-XXXX`. From a phone or computer you can there:
- upload, choose, rename, delete and back up payloads (`.dol`, payload `.uf2` or raw);
- update the firmware into its second slot, on trial with a fallback by itself;
- change the settings, and start the console's own menu once.

See the [README](https://github.com/r3mko/PicoBoot-WiFi#readme) for the wiring, installing, upgrading from PicoBoot-DX, and recovery.

**Files:**

| File | What it is |
|---|---|
| `picoboot-wifi-1.0.0.uf2` | The USB install: a first install, an upgrade from PicoBoot-DX, or a recovery. Copy it onto the Pico's drive (hold BOOTSEL while connecting USB). It leaves the payloads in place |
| `picoboot-wifi-1.0.0-update.bin` | The update over Wi-Fi, for later releases' installs from this one (the Firmware tab, or the CLI's `update`) |
| `picoboot-wifi.py` | The command-line tool (Python 3, standard library only) |
| `SHA256SUMS` | The SHA-256 of each file |

**Notes:**
- **The default Wi-Fi password is `picoboot`.** Change it: it's the only protection, and anyone who knows it can change the firmware and the payloads.
- **Tested on a DOL-001.** The DOL-101 should work but hasn't been tested.
- **`.dol` files** must be built as an IPL replacement (loaded at `0x81300000`), such as gekkoboot. For Swiss, use `PicoBoot/swiss_rXXXX.uf2` from its release.
- **5 V wiring to VSYS** (through a Schottky diode) is recommended; the 3V3 wiring works too.
