A small update to 1.0.2: the built-in gekkoboot is now the official r9.4 release build.

**What changed:**
- **The built-in gekkoboot is the r9.4 release's own build.** Until now, PicoBoot-WiFi carried a build of the same r9.4 source from gekkoboot's automatic builds, which shows "gekkoboot undefined" at the top of its screen. The built-in is now rebuilt from gekkoboot's r9.4 release, and it makes exactly the release's own `gekkoboot_pico.uf2`. Its screen shows "gekkoboot r9.4" (hold D-Pad Down at power-on to keep the screen up).

Both builds come from the same source and are the same size, so gekkoboot behaves as before. The built-in only boots when it's the choice, or when the chosen payload isn't valid. Your payloads, the settings, the page and the command-line tool are unchanged, so the update is optional.

**Updating from 1.0.2, 1.0.1 or 1.0.0:** install `picoboot-wifi-1.0.3-update.bin` on the Firmware tab, or with `python3 picoboot-wifi.py update picoboot-wifi-1.0.3-update.bin`. It starts on trial, and it keeps itself after the next power-on that boots the console. A first install or a recovery uses the UF2, as the [README](https://github.com/r3mko/PicoBoot-WiFi#readme) describes.

**Files:**

| File | What it is |
|---|---|
| `picoboot-wifi-1.0.3.uf2` | The USB install: a first install, an upgrade from PicoBoot-DX, or a recovery. Copy it onto the Pico's drive (hold BOOTSEL while connecting USB). It leaves the payloads in place |
| `picoboot-wifi-1.0.3-update.bin` | The update over Wi-Fi from 1.0.2, 1.0.1 or 1.0.0 (the Firmware tab, or the CLI's `update`) |
| `picoboot-wifi.py` | The command-line tool (Python 3, standard library only), the same as in 1.0.0 |
| `SHA256SUMS` | The SHA-256 of each file |

**Notes:** as for 1.0.0. Change the default Wi-Fi password (`picoboot`). Tested on a DOL-001.
