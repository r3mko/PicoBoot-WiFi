Ordinary `.dol` files now boot from a payload slot.

**What's new:**
- **Ordinary `.dol` files work.** Until now, the page and the command-line tool only took a `.dol` built as an IPL replacement, such as gekkoboot. Now they also take an ordinary one, such as Swiss's regular `swiss_rXXXX.dol` or cubiboot's `ipl.dol`. A small loader goes in front of it. At power-on, it puts the program in place, sets up what the console's own menu would have set up, and starts it. The page says so when you choose the file.
- **What's refused:** a `.dol` whose sections reach `0x81300000` or above, where the loader runs, or low memory below `0x80003100`, which the loader fills. Programs linked the usual way, from `0x80003100`, are fine. The slots hold up to 1.5 MB, as before.

A `.dol` built as an IPL replacement converts exactly as before, and the payloads you have stay as they are. Apart from the page, the firmware is unchanged.

**Updating from 1.0.3, 1.0.2, 1.0.1 or 1.0.0:** install `picoboot-wifi-1.1.0-update.bin` on the Firmware tab, or with `python3 picoboot-wifi.py update picoboot-wifi-1.1.0-update.bin`. It starts on trial, and it keeps itself after the next power-on that boots the console. A first install or a recovery uses the UF2, as the [README](https://github.com/r3mko/PicoBoot-WiFi#readme) describes. The new command-line tool converts ordinary `.dol` files by itself, also for a Pico still on 1.0.x, so replace your copy of `picoboot-wifi.py`.

**Files:**

| File | What it is |
|---|---|
| `picoboot-wifi-1.1.0.uf2` | The USB install: a first install, an upgrade from PicoBoot-DX, or a recovery. Copy it onto the Pico's drive (hold BOOTSEL while connecting USB). It leaves the payloads in place |
| `picoboot-wifi-1.1.0-update.bin` | The update over Wi-Fi from 1.0.3, 1.0.2, 1.0.1 or 1.0.0 (the Firmware tab, or the CLI's `update`) |
| `picoboot-wifi.py` | The command-line tool (Python 3, standard library only), new in this release for ordinary `.dol` files |
| `SHA256SUMS` | The SHA-256 of each file |

**Notes:** as for 1.0.0, except for `.dol` files. Change the default Wi-Fi password (`picoboot`). Tested on a DOL-001.
