A fix for consoles that start their own menu instead of the payload.

**What changed:**
- **CS is no longer pulled up.** Since 1.0.0, PicoBoot-WiFi pulled up the IPL chip's select line (CS), to stop a false edge at start-up on some consoles. On another DOL-001 that pull-up caused extra edges of its own: on about half the power-ons, the payload went out early and the console started its own menu. CS is now left as the Pico's reset leaves it, as PicoBoot does. The start-up check that counts a transfer only if the clock runs still ignores the false edge, and both test consoles boot every time.
- **A wiring note in the README:** keep the ground wire short, to a ground point near U10. On that console a long ground wire also kept the payload from reaching the console. The Diagnostics tab showed it as far too many CS edges: tens or hundreds of thousands, where 225 more than the payload's transfers are expected (285 for the built-in gekkoboot).

Your payloads, the settings, the page and the command-line tool work as before.

**Updating from 1.1.0 or 1.0.x:** install `picoboot-wifi-1.1.1-update.bin` on the Firmware tab, or with `python3 picoboot-wifi.py update picoboot-wifi-1.1.1-update.bin`. It starts on trial, and it keeps itself after the next power-on that boots the console. A first install or a recovery uses the UF2, as the [README](https://github.com/r3mko/PicoBoot-WiFi#readme) describes.

**Files:**

| File | What it is |
|---|---|
| `picoboot-wifi-1.1.1.uf2` | The USB install: a first install, an upgrade from PicoBoot-DX, or a recovery. Copy it onto the Pico's drive (hold BOOTSEL while connecting USB). It leaves the payloads in place |
| `picoboot-wifi-1.1.1-update.bin` | The update over Wi-Fi from 1.1.0 or 1.0.x (the Firmware tab, or the CLI's `update`) |
| `picoboot-wifi.py` | The command-line tool (Python 3, standard library only), the same as in 1.1.0 |
| `SHA256SUMS` | The SHA-256 of each file |

**Notes:** as for 1.0.0, except for `.dol` files (see 1.1.0). Change the default Wi-Fi password (`picoboot`). Tested on two DOL-001s.
